# Meme Stock Sentiment Dashboard

A single-screen app that shows (mocked) social sentiment for a stock ticker. No real API integrations, no database, no auth — dummy data only, seeded deterministically per ticker.

## Backend (Express)

```
cd backend
npm install
npm start
```

Runs on `http://localhost:5001`. Endpoint: `GET /api/sentiment/:ticker`.

## Frontend (Vite + React)

```
cd frontend
npm install
npm run dev
```

Runs on `http://localhost:5173`. Start the backend first — the frontend calls it directly at `http://localhost:5001`.

## Notes

- Sentiment values are generated by hashing the ticker symbol, so the same ticker always returns the same numbers, but different tickers look different.
- Unrecognized tickers still return data, with a `note` field indicating it's simulated.
